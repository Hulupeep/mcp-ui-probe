Welcome to the UI-Probe testing playground! This is your sandbox for exploring UI-Probe's powerful automation capabilities. Each test page demonstrates different features and challenges for web testing.

🚀 How to Use the Playground

Quick Start with Claude

  1. Make sure the playground server is running: npm run test:server
  2. In Claude, navigate to any test page below
  3. Use natural language or explicit commands to interact
  4. Watch UI-Probe handle complex scenarios automatically

Natural Language Example:

# Just describe what you want
"Test the signup form on the main page"
"Fill out the contact form with test data"
"Click all the buttons and verify they work"

Explicit Commands Example:

# Use specific commands for precise control
navigate "http://localhost:8081/test"
fill_form {"email": "test@example.com"}
click_button "Submit"
verify_page {"expectedContent": ["Success"]}

Journey Recording Example:

# Record interactions for instant replay
journey_record_start {"name": "Complete Signup"}
# Perform your interactions...
journey_record_stop {"tags": ["auth"]}
# Replay later with:
journey_play {"journeyId": "journey_123"}
